(not in Git). Variants are "Reverse" (for dark backgrounds), SVG.

|---|---|---|

Console screenshots for backup slides also go in this directory, as lossless
WebP (`demo3-<part>-<what>.webp`, converted from the original PNG - see the
"Demo scripts" section of the root CLAUDE.md). The deck shows a placeholder
until each file exists.
